# Raven Drop APK

Build Android de desenvolvimento do prototipo Raven Drop. Esta versao importa o novo pacote de armas,
substitui o paraquedas e a caixa de loot por modelos 3D texturizados, mantendo os ajustes de camera,
locomocao, combate, aim assist e HUD mobile.

## Download

Baixe `RavenDrop-Android.apk` e permita a instalacao de aplicativos de fontes externas no Android.

## Requisitos

- Android 8.0 (API 26) ou superior
- Arquitetura ARM64
- Orientacao horizontal
