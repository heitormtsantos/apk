# GLB/GLTF map import

This project includes Unity glTFast (`com.unity.cloud.gltfast`) so licensed `.glb` and `.gltf` files can be imported by placing them under this folder.

Workflow:

1. Confirm the asset license allows use in your game.
2. Copy the `.glb` or `.gltf` into this folder.
3. Wait for Unity to import it.
4. Drag the imported prefab/model into `BattleRoyalePrototype`.
5. Add colliders where players should walk or hide.

Do not import assets copied from existing games without explicit permission.
